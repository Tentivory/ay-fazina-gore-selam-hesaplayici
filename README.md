# Ay Fazına Göre Selam Hesaplayıcı

## Bu Ne?

Bu, insanlık tarihinin en önemli bilimsel başarısıdır. Ay fazına göre tam olarak ne zaman ve nasıl "selam" demeniz gerektiğini hesaplar. NASA, ESA, TÜBİTAK ve mahalle bakkalı onayladı. (Onaylamadı.)

Eğer bu programı kullanmazsanız, sosyal hayatınız çöker. Garantili.

## Nasıl Çalışır?

1. Python 3 yükleyin (yoksa yükleyin, bu program onsuz çalışmaz, şaşırtıcı değil mi?).
2. `python selam_hesapla.py` yazın.
3. Ay fazınızı öğrenin.
4. Selam verin (veya vermeyin, dolunaydaysa).
5. Mutlu olun. (Olmazsanız da sorun değil, bu program mutluluk garantisi vermez.)

## Özellikler

- Tamamen bilimsel (değil).
- Rastgele değil, formüllü (formül rastgele).
- Türkçe. Çünkü Türkçe güzel.
- Gizli mesaj içerir. Bulursanız tebrikler, bulamazsanız da tebrikler.
- Hiçbir şey yapmaz ama yapar gibi görünür.

## Uyarı

Bu programı kullanmak sosyal izolasyona, aşırı selam vermeye veya hiç selam vermemeye yol açabilir. Sorumluluk kabul etmiyoruz. Mahkemeye çıkarsanız "Grok yaptı" deyin.

## Katkıda Bulunma

Lütfen katkıda bulunmayın. Bu program mükemmel. Bozarsınız.
